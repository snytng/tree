# My Diagram App バックログ (Backlog)

## 1. [B-001] インライン編集機能 (Inline Editing)
- **概要**: ノードをダブルクリックすることで、その場でタイトル（ラベル）を編集できる機能。
- **目的**: Markdownファイルを直接書き換えなくても、キャンバス上で直感的に思考を具体化できるようにする。編集内容は Yjs を通じて `projectFiles` (spec.md/design.md) に書き戻す。

## 2. [B-002] 詳細表示パネル (Detail Panel)
- **概要**: 選択中のノードの ID に対応する Markdown セクションの全文を画面右側のサイドパネルに表示する機能。
- **目的**: 図面上の「ハコ」と、その背景にある「詳細な仕様・設計内容」をシームレスにリンクさせ、トレーサビリティを体現する。

## 3. [B-003] オートレイアウト中の手動位置微調整 (Manual Tweaks in Auto-Layout)
- **概要**: 自動レイアウトが ON の状態でも、特定のノードに対してユーザーが手動でオフセット（微調整）を加えられるようにする。
- **目的**: 基本的な整列はアルゴリズムに任せつつ、「このノードだけは少し離したい」といった人間の感性によるレイアウト調整を許容する。

## 4. [B-004] 構造的ツリー編集ショートカット (Structural Tree Shortcuts)
- **概要**: `Ctrl + 矢印キー` を使用して、フォーカス中のノードをツリー構造内で移動させる機能。
    - **Ctrl + Up/Down**: 兄弟ノード間での順序入れ替え。
    - **Ctrl + Right**: 上にある兄弟ノードの子ノードに移動（階層を下げる）。
    - **Ctrl + Left**: 親ノードの弟ノードに移動（階層を上げる）。
- **ルール**: 移動時は子ノード（サブツリー）をすべて引き連れて移動する。
- **目的**: マウスを使わずに、アウトライナー感覚で図面の論理構造を高速に組み替えられるようにする。
