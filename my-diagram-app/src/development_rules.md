現在、React Flowを使用して「ホワイトボードのように自由で、かつグラフDBのような意味論を持つ」モデリングツールのプロトタイプを作成中です。

1. 現在の状況:

    Vite + React + React Flowで、ノード（四角）とエッジ（線）を動的に追加・接続できる最小構成のモックが動作済み。

    ユーザーは「最初はスキーマレスに、徐々に構造化（属性定義）」していく成長型のツールを目指している。

2. 次のステップ:
このプロトタイプを「共同編集（リアルタイム同期）」に対応させたい。以下の技術スタックを用いた実装コードを提案してください。

    同期エンジン: Yjs (CRDT) を使用。

    通信: まずはサーバー不要でブラウザ間通信ができる y-webrtc 、または簡単なバックエンドで済む y-websocket を想定。

    要件: * nodes と edges の状態を Yjs の Y.Doc で管理し、複数タブ/ブラウザ間でリアルタイムに同期させる。

        React Flow の onNodesChange や onEdgesChange を Yjs の共有型（Shared Types）と連動させる。

3. お願い:
この構成を実現するための、App.jsx の修正案と必要なライブラリのインストールコマンドを教えてください。
