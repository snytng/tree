# My Diagram App

「最初はスキーマレスに、徐々に構造化」していく成長型のモデリングツールです。ホワイトボードのような自由度と、グラフ構造の意味論を兼ね備えた、リアルタイム共同編集可能なダイアグラム作成アプリケーションです。

## 🚀 主な機能

- **リアルタイム共同編集**: Yjs (CRDT) を活用し、複数ユーザー間でのシームレスな同時編集を実現。
- **柔軟なレイアウト**: 高度な自動レイアウト（再帰的領域スタッキング）と手動配置を動的に切り替え可能。
- **構造的ツリー編集**: アウトライナー感覚で操作できる強力なキーボードショートカット（階層上げ・下げ、順序入れ替え）。
- **AI アシスタント連携**: Model Context Protocol (MCP) を通じた AI による図面操作（読み取り・追加・修正）に対応。
- **Markdown 連携**: 人間が読み書き可能な単一の Markdown 形式でのインポート/エクスポートおよび階層テキストのコピペに対応。
- **フォーカスモード**: 特定のノードに関連する祖先・子孫のみを抽出表示し、複雑な図面を整理。

## 🛠 技術スタック

- **Frontend**: React (Vite) / React Flow
- **Conflict Resolution (CRDT)**: Yjs
- **Networking**: y-webrtc / y-websocket
- **Layout Engine**: Dagre / カスタム領域スタッキングアルゴリズム
- **AI Bridge**: Model Context Protocol (MCP)
