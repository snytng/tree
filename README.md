# My Diagram App

「最初はスキーマレスに、徐々に構造化」していく成長型のモデリングツールです。ホワイトボードのような自由度と、グラフ構造の意味論を兼ね備えた、リアルタイム共同編集可能なダイアグラム作成アプリケーションです。

## 🚀 主な機能

### コア機能
- **リアルタイム共同編集**: Yjs (CRDT) を活用し、複数ユーザー間でのシームレスな同時編集を実現。
- **マルチプロジェクト管理**: 複数のプロジェクトをブラウザ内で作成・切り替え・管理。プロジェクトごとに独立したデータ領域。
- **柔軟なレイアウト**: 高度な自動レイアウト（再帰的領域スタッキング）と手動配置を動的に切り替え可能。

### マルチビュー
- **ノードグラフ**: ツリー構造のノードとエッジを操作するメインビュー。
- **一覧表ビュー**: ノードデータをExcel風スプレッドシートで閲覧・操作。右クリックから対象ノードへフォーカス遷移可能。
- **ブロック図ビュー**: ノードを矩形・ひし形・楕円等のシェイプで自由配置。色・サイズ変更、浮動エッジに対応。
- **タブ管理**: VS Code風のタブバーで複数ビューを同時に開いて切り替え。ドラッグ並び替え・右クリックメニュー対応。

### 編集・操作
- **構造的ツリー編集**: アウトライナー感覚で操作できる強力なキーボードショートカット（階層上げ・下げ、順序入れ替え）。
- **ノードクラス継承**: ノード追加時に親/兄弟のクラス属性を自動継承。
- **自動編集モード**: ノード選択中に文字キーを押すだけでインライン編集を開始。
- **選択メニュー**: 複数ノード選択→右クリックでブロック図への一括追加が可能。
- **フォーカスモード**: 特定のノードに関連する祖先・子孫のみを抽出表示し、複雑な図面を整理。

### 外部連携
- **AI アシスタント連携**: Model Context Protocol (MCP) を通じた AI による図面操作（読み取り・追加・修正・削除）に対応。マルチクライアント同時接続対応。
- **Markdown 連携**: 人間が読み書き可能な単一の Markdown 形式でのインポート/エクスポートおよび階層テキストのコピペに対応。

### UI/UX
- **グローバルコマンドバー**: Linear/Figma風のコマンドバーでプロジェクト操作・ビュー管理を統合。
- **ブラウザダイアログ**: プロジェクト/ダイアグラムの検索・リネーム・削除をモーダルUIで実行。
- **モダンツールバー**: フローティング・折りたたみ可能なツールバー。エッジ追加時のラバーバンド表示対応。
- **デバッグ支援**: UIイベントのリングバッファログとワンクリックデバッグ情報コピー。

## 🛠 技術スタック

- **Frontend**: React 19 (Vite 8) / React Flow 11
- **Conflict Resolution (CRDT)**: Yjs
- **Networking**: y-webrtc / y-websocket
- **Persistence**: y-indexeddb / localStorage
- **Layout Engine**: Dagre / カスタム領域スタッキングアルゴリズム
- **AI Bridge**: Model Context Protocol (MCP) — SSE トランスポート
